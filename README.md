# 서버 경제 계산기

정적 HTML/CSS/JavaScript로 만든 마인크래프트 서버 경제 계산기입니다.

## 실행
- `index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.
- 별도 설치, 빌드, 데이터베이스가 필요하지 않습니다.

## 무료 배포
1. GitHub에서 새 공개 저장소를 만듭니다.
2. `index.html`을 저장소 최상위에 업로드합니다.
3. 저장소 Settings → Pages → Deploy from a branch → `main` / `root`를 선택합니다.
4. 표시되는 `https://사용자명.github.io/저장소명/` 주소를 공유합니다.

Cloudflare Pages에서도 정적 사이트로 배포할 수 있습니다.

## 가격 저장 방식
- 농작물 포대 10종의 세트 가격을 수정하면 연결된 가공 재료의 기본 단가가 자동으로 다시 계산됩니다.
- 초기 공통 기준가는 코드에 포함되어 모든 방문자에게 동일하게 표시됩니다.
- 이용자의 '내 적용가', 조달 방식, 드롭 확률은 해당 브라우저의 localStorage에 저장됩니다.
- 현재 버전은 이용자끼리 개인 수정 가격을 공유하지 않습니다.
- 공통 기준가를 모든 방문자에게 변경하려면 `index.html`의 `baseItems`, `cropPacks`, `recipes` 데이터를 수정한 뒤 다시 배포해야 합니다.
- 공통 가격을 관리자 화면에서 변경하고 모든 이용자에게 즉시 동기화하려면 별도 DB/API가 필요합니다.

## 기본 계산 가정
- 1세트 64개, 1셜커 1,728개
- 포대 1개는 농작물 9개, 포대 1세트는 농작물 576개
- 생선 1셜커 460,000원, 생선 1개당 손질된 생선살 2개
- 철 블록 1세트 80,000원, 철 블록 1개는 철괴 9개, 철 양동이 제작은 철괴 3개, 양동이당 소금 6개
- 물병 원가 1원, 정제수 초기 유저 거래 기준가 5원
- 밀가루와 손질된 감자는 직접 채집으로 기본 설정되어 현금 원가 0원. 다른 농작물 가공 재료는 기본적으로 구매로 설정
- 2배 드롭 기본 0%
- 벌집 조각 가격은 미확인으로 두어 팬케이크 원가/수익을 미등록 처리
- 수익 계산은 재료비 기준이며 제작 노동·도구 등 부대비용은 제외

## 중요
가격 데이터와 레시피는 현재 대화에서 확인된 초기값입니다. 서버의 실제 레시피/드롭 규칙이 다르면 가격 관리 및 레시피 데이터를 조정해야 합니다.

## 사용자 데이터 저장 방식
- 내 가격, 조달 설정, 대시보드 고정 요리는 현재 사용 중인 브라우저의 `localStorage`에 저장됩니다.
- 같은 브라우저·같은 기기에서 다시 방문하면 유지되지만, 다른 기기/브라우저와 자동 동기화되지는 않습니다.
- 브라우저 데이터 삭제 또는 시크릿 모드 사용 시 저장 내용이 사라질 수 있습니다.
- 여러 이용자 간 데이터 공유나 계정 기반 동기화에는 별도 백엔드/데이터베이스가 필요합니다.
